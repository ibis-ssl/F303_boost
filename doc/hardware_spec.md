# F303_boost ハードウェア／周辺機能仕様

本資料は`orion_F303_boost_v3.ioc`と現在のファームウェア実装を基にした概要です。回路定数やコネクタ配線の確定には回路図も併用してください。

## MCUとクロック

- MCU: STM32F303CBT6（Cortex-M4F、LQFP48）
- システムクロック: 72 MHz（8 MHz HSE、PLL x9）
- APB1: 36 MHz（タイマクロック72 MHz）
- APB2: 72 MHz
- 監視: IWDG

## 回路構成
昇圧チョッパでキャパシタを充電し､放電回路を使用して､2つあるコイルのどちらかに通電して放電します｡
充電/放電電圧･電流については､回路的なマージンが非常に少なく､既にチューニング済みなので､特に出力や損失が増大しないように注意してください
電源はリポ6セル､充電回路はSiC MOSFET(UJ3C065080T3S)で10uHのコイルをスイッチングし､450V,680uF x2のコンデンサを充電します｡
放電コイルは6.9～7.4Ωのものと､10.8～12.7Ω(10mH前後,ただし鉄心なし状態)の2種類あり､出力はSi MOSFET(IPD60R180P7 x3パラ)で行います｡

## 制御対象

- 昇圧チョッパFET駆動PWM: TIM2 CH4
- 放電コイル出力調整PWM: TIM3 CH1／CH2（ストレート／チップ）
- スイッチトキャパシタ式ゲートドライバ負電源の駆動PWM: TIM4 CH2
- 電源出力イネーブル: GPIO
- 光学センサ: ADNS3080（SPI1）

## アナログ計測

ADC1、ADC3、ADC4のInjected conversionを使用し、次を計測します。

- バッテリ電圧
- ゲートドライバ正／負電源
- 昇圧電圧
- バッテリ電流
- FET温度
- コイル1／2温度

## 通信

- CAN: PA11（RX）／PA12（TX）、1 Mbit/s、normal mode
- UART1: PA9（TX）／PA10（RX）、2,000,000 baud
- SPI1: ADNS3080接続

## 保護処理

現在の実装では、次の異常を検出するとPWMと電源出力を停止し、CANでエラーを通知します。

- バッテリ低電圧／過電圧
- 短絡／過電流
- ゲートドライバ正負電源異常
- 昇圧電圧異常
- FET過熱
- コイル過熱

しきい値の実体は`Core/Src/main.c`の`protecter()`を参照してください。高電圧を扱うため、実機試験では放電状態、電源制限、非常停止手段を確認してください。
